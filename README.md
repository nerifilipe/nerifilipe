### Selected projects

#### [Unison](https://github.com/nerifilipe/unison)

Music streaming application with personal playlists, audio uploads, and synchronized listening rooms. Combines a React interface with a Spring Boot backend, WebSocket communication, and audio processing.

`Java` `Spring Boot` `React` `TypeScript` `PostgreSQL` `Docker`

#### [FileNest](https://github.com/nerifilipe/FileNest)

Local document organizer that suggests filenames and folders from document content. Includes optional local AI, editable previews, operation history, and undo.

`Python` `FastAPI` `React` `TypeScript` `SQLite` `Ollama`

#### [Industrial Monitoring Platform](https://github.com/nerifilipe/industrial-monitoring-platform)

Industrial monitoring dashboard for machines, simulated sensor readings, and threshold alerts. Includes authentication, historical data visualization, and a Docker-based setup.

`Java` `Spring Boot` `React` `PostgreSQL` `Docker`

#### [AI-Powered Customer Support System](https://github.com/Gabriel0342/AI-Powered-Customer-Support-System)

Collaborative project exploring AI-assisted customer support, with customer and support-team interfaces and a knowledge base.

`Python` `Ollama`
